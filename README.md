# Поиск максимального значения в массиве

Консольное приложение для поиска максимального значения в массиве целых чисел, реализованное на языке Go.  
  
Программа генерирует массив случайных положительных целых чисел и определяет его максимальный элемент двумя способами: последовательным перебором в одном потоке и параллельной обработкой с использованием восьми горутин. Для каждого способа измеряется время выполнения, что позволяет сравнить их производительность.  
  
Учебный проект, выполненный в рамках прохождения курса «Основы разработки на языке Go».

## Установка и запуск

1. Проверьте наличие Go на компьютере.
2. Скачайте проект.
3. Перейдите в папку проекта и запустите программу:

```
go run .
```
